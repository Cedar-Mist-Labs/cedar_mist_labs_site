Privacy

Last updated October 30, 2026

This policy covers the website at cedarmistlabs.com. Cedar Mist Labs products, such as Cedar Mist Resources, have their own privacy policies.

What this site collects

Cedar Mist Labs does not collect personal information through this site. It has no forms, accounts, cookies, or analytics, and it does not load scripts or fonts from other companies.

Hosting

This site is hosted on GitHub Pages. GitHub may log visitors' IP addresses to keep the service secure. Cedar Mist Labs does not receive or use those logs. GitHub's handling of that data is described in the GitHub Privacy Statement.

Email

If you email us, we receive your email address and whatever you include in your message. We use it only to reply to you and keep it only as long as that requires. We don't sell it or share it for marketing.

Changes

If this policy changes, the new version will appear on this page with a new date.
